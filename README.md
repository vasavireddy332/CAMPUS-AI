# 🎓 CampusAI – Smart Campus AI Assistant

CampusAI is an AI-powered smart campus assistant designed to help students with academics, programming, campus activities, projects, and career preparation.

## 🚀 Live Demo

👉 [Open CampusAI][(https://campus-collegeai.streamlit.app/)]

## 💻 GitHub Repository

👉 [View Source Code](https://github.com/vasavireddy332/CAMPUS-AI)

## ✨ Features

- 🤖 AI-powered student assistant
- 📚 Study planning
- 💻 Programming guidance
- 🎯 Career and interview preparation
- 💡 Project ideas
- 📅 Campus events
- 📖 Learning resources
- 🎨 Student-friendly interface

## 🛠️ Technologies Used

- Python
- Streamlit
- Google Gemini API
- Google GenAI SDK
- python-dotenv

## 🔐 Security

API keys are stored securely using Streamlit Secrets and are not included in the GitHub repository.
